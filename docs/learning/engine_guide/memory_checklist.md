# Memory Analysis Checklist

```text
[ ] Persistent modeled state identified?
[ ] Transactional copies identified?
[ ] Stage/step temporary containers identified?
[ ] Container copies versus deep semantic copies distinguished?
[ ] Cache size/lifetime understood?
[ ] Historical observer/telemetry retention identified?
[ ] Size growth expressed in relevant variables?
[ ] Lifetime stated (stage/step/run/experiment)?
[ ] Peak versus cumulative/retained memory distinguished?
[ ] Need for tracemalloc or streaming/aggregation considered?
```
