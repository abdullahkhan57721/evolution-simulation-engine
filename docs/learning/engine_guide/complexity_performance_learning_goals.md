# Complexity and Performance Learning Goals

After the engineering-analysis material, you should be able to:

```text
define scale variables before Big-O
use O/Theta and amortized reasoning appropriately
know common Python list/dict/tuple costs
analyze delegated work compositionally
reason about auxiliary space and memory lifetime
separate kernel overhead from domain algorithm cost
distinguish hotness from architectural importance
use profile vs benchmark vs tracemalloc appropriately
explain constant-factor improvements with unchanged Big-O
identify time-space tradeoffs
review semantics-sensitive optimizations
balance measured performance with readability/maintainability
```
