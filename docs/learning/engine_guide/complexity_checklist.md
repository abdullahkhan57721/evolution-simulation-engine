# Complexity Analysis Checklist

```text
[ ] Define every scale variable.
[ ] Choose time and/or auxiliary-space question.
[ ] Separate local structural work from delegated work.
[ ] State average/worst/amortized assumptions where relevant.
[ ] Do not treat one function call as O(1) if the callee is arbitrary.
[ ] Include result/container construction costs.
[ ] Record memory lifetime when useful.
[ ] Consider how variables change through simulation time.
[ ] Pair theoretical analysis with measurement when practical performance matters.
```
