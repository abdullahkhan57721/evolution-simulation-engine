# Engineering Learning Path

If your immediate goal is to become better at reading/reviewing production code,
use this shorter path through the textbook.

```text
Software Architecture Primer
        ↓
Architecture Quality
        ↓
Computational Complexity & Performance Thinking
        ↓
Simulation Fundamentals
        ↓
Kernel Mental Model
        ↓
Kernel Runtime
        ↓
Engineering Anatomy of the Kernel
        ↓
Reading the Kernel Source
        ↓
Reasoning About Proposed Changes
        ↓
Complexity Exercises + Debugger Labs
        ↓
Capstones
```

Keep the [Engineering Review Cards](engineering_review_cards.md) and
[High-Value Contrast Reference](contrast_reference.md) open as reference only
after you have attempted the deeper explanations.

The target skill is:

> Open unfamiliar code, reconstruct its responsibility and invariants, reason
> about scaling/memory and measured performance, assess readability/change risk,
> and decide whether a proposed modification belongs there.
