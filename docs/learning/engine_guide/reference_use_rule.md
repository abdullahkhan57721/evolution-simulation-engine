# How to Use the Reference Pages

Reference pages are intentionally compact. They are for retrieval after conceptual
understanding, not a shortcut around it.

Use:

```text
Cheat Sheet / Quick References
    after attempting recall

Worksheets
    when solving/reviewing something independently

Glossary
    when terminology blocks understanding

Engineering Review Cards
    after you can explain the deeper review method
```

If a reference item is recognizable but you cannot explain why it is true, return
to the corresponding chapter.
