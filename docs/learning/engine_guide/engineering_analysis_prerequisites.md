# Engineering Analysis Prerequisites

Before the complexity/performance chapters, you should already be comfortable with:

```text
Python loops/lists/dicts/tuples
references versus copied objects
functions/method calls
basic contracts/interfaces
state versus immutable configuration
```

You do not need prior formal algorithms coursework. The chapter introduces the
notation it uses and keeps analysis grounded in engine code.

After the chapter you are ready for:

```text
Engineering Anatomy of the Kernel
Performance Case Studies
Source Analysis Method
Complexity Exercises
```
