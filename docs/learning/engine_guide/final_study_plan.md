# Suggested Study Plan

The textbook is large enough that reading it straight through in one sitting is
not the best learning strategy.

## Session 1 — Architecture skeleton

Read:

```text
Start Here
How to Use This Textbook
Software Architecture Primer
Architecture Quality
```

Then redraw the three-layer architecture from memory.

## Session 2 — Complexity and simulation

Read:

```text
Computational Complexity & Performance Thinking
Simulation Fundamentals
```

Then do three scaling thought experiments and one predict-before-running prompt.

## Session 3 — Evolution

Read:

```text
General Evolution
Biological Specialization
```

Explain the full model without using biological vocabulary, then map it back onto
biology.

## Session 4 — Kernel

Read:

```text
Kernel Mental Model
Public API
Kernel Runtime
Design Rationale & Invariants
```

Redraw the run/step/stage call flow from memory.

## Session 5 — Engineering analysis

Read:

```text
Engineering Anatomy of the Kernel
Performance Case Studies
```

Fill out one Engineering Review Card yourself for a component not used as the main
worked example.

## Session 6 — Source and debugger

Read/use:

```text
Reading the Kernel Source
Source Analysis Method
Debugger Labs
```

Predict before every breakpoint.

## Session 7 — Independent design

Use:

```text
Reasoning About Proposed Changes
Complexity Exercises
Capstones
```

Keep the cheat sheet closed until after each attempt.

## Later spaced review

Every few days, retrieve one of these without looking:

```text
master architecture map
stage invariant order
state/context contrast
general evolution model
reproduction role distinctions
StageCoordinator complexity expression
engineering review questions
```

If recall is weak, return to the focused chapter rather than restarting the entire
book.
