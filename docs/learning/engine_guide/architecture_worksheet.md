# Blank Architecture Worksheet

Use this when designing a feature or milestone.

```text
Feature / change:

Scientific/domain meaning:

Owning architectural layer:

Mutable state required:

Immutable configuration / policies required:

Candidate event/proposal:

Potential conflicts:

When should randomness be consumed?

Does accepted-only materialization help?

Who owns mutation?

Telemetry / observation required:

Important scaling variables:

Expected time complexity / delegated costs:

Memory amount + lifetime:

Execution frequency / likely hotness:

Readability considerations:

Maintainability / change radius:

Existing contract that should express this:

Evidence of any lower-layer deficiency:

Focused invariants/tests:

What would go wrong in the naive design?
```
