# Final Practice Structure

Practice follows fading scaffolds:

```text
GUIDED
predict-before-run prompts
debugger labs
worked source review

SEMI-GUIDED
complexity exercises
scaling thought experiments
proposed-change reviews

INDEPENDENT
blank architecture/code/performance/source worksheets
mini-kernel reconstruction
capstones
```

Hints should be separate from exercises so the reader must make an initial
attempt before seeing the reasoning.
