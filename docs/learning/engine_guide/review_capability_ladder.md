# Review Capability Ladder

```text
READ
    I can follow the code.

EXPLAIN
    I can state why the design exists.

ANALYZE
    I can reason about invariants, complexity, memory, and tradeoffs.

REVIEW
    I can evaluate someone else's proposed change.

DESIGN
    I can choose the correct boundary and implementation approach myself.
```

The textbook intentionally progresses upward through this ladder. The final
capstones target DESIGN, not merely READ.
