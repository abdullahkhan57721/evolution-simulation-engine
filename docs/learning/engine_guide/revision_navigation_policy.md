# Revision Navigation Policy

Primary MkDocs navigation should expose the coherent learning path, not every
supporting reference page.

Primary nav:

```text
foundations
evolution
kernel
engineering analysis
worked examples/source reading
practice
reference indexes
```

Secondary compact pages remain discoverable through:

```text
Engineering Analysis Index
Practice Index
Reference Index
MkDocs search
cross-links
```

This keeps the textbook comprehensive without making the sidebar overwhelming.
