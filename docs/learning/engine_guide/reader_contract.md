# Reader Contract

You do not need to memorize every page.

The textbook promises to provide:

```text
mental models before jargon
progressive disclosure
real repository code/tests
multiple navigation paths
explicit contrasts/misconceptions
practice with fading scaffolds
reference pages for later retrieval
```

Your side of the learning process is:

```text
predict before running
explain ideas in your own words
attempt exercises before hints
reconstruct diagrams from memory
use source/tests rather than only prose
return after spacing
```

The goal is independent reasoning, not completion percentage.
