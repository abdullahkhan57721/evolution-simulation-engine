# Engineering Analysis Completion Criteria

The engineering-analysis portion of the textbook is complete for this milestone
when the reader has all of the following:

```text
conceptual intro to complexity/performance
Python-relevant operation costs
compositional kernel complexity analysis
memory amount + lifetime reasoning
hot-path/frequency reasoning
profiling/benchmarking/allocation distinction
repository performance case studies
readability/maintainability/extensibility/testability framework
source review cards and worked example
architecture/code/performance worksheets
wrong-but-plausible review exercises
scaling thought experiments
mastery levels and independent capstones
scope/maintenance guardrails
```

Further additions should be driven by real use of the textbook, not by an attempt
to enumerate every software-engineering topic.
