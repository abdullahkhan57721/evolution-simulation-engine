# Final Ergonomics Rules

```text
Primary sidebar stays short enough to scan.
Supporting pages live behind indexes/search/cross-links.
Every major page starts with orientation/motivation.
Every major page ends with mastery/next step.
Contrast tables handle easily confused concepts.
Code appears after mental model/pseudocode where possible.
Reference pages remain compact.
Exercises keep answers/hints separate.
Source links point to current repository paths, not copied stale files.
Authority warnings remain visible at entry points.
```

The textbook should feel navigable both linearly and when opened in the middle.
