# Reading Modes

The same textbook can be used three ways.

## Course mode

Follow the five-part sequence from foundations to capstones.

## Reference mode

Use search, contrast tables, review cards, glossary, and worksheets to answer a
specific code-reading/design question.

## Repository-review mode

Open the source/test/ADR first, then use the textbook to explain unfamiliar
concepts or evaluate complexity/quality tradeoffs.

The textbook should support all three modes without becoming authoritative over
the repository itself.
