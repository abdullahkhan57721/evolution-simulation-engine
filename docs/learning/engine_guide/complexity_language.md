# Recommended Complexity Language

Prefer precise phrases:

```text
"average O(1) dictionary lookup"
"amortized O(1) list append"
"O(Q) stage-local proposal references"
"O(R) kernel structural iteration, excluding application cost"
"C_domain_copy(N) because domain copy complexity is opaque to the kernel"
"potential O(N^2) pairwise domain algorithm"
```

Avoid vague phrases:

```text
"basically constant"
"the engine is linear"
"this method is O(n)" without defining n
"memory is O(n)" without saying what is retained or for how long
```
